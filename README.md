# 呼吸道處置與氣管插管：講義重點

Airway Management & Endotracheal Intubation 課程的講義重點整理，以 GitHub Pages 發布。

內容包含：插管適應症、評估與準備（LEMON、擺位、預給氧、PEEP）、策略與器材（Plan A–D、DL/VL、Cooper manoeuvre）、插管藥物、RSI / DSI / 清醒插管、困難呼吸道（bougie、Vortex、CICO），以及特殊情境（HNI、右心衰竭、SALAD）。

本頁為教學用途，不能取代臨床判斷。藥物劑量請依院內規範確認。
